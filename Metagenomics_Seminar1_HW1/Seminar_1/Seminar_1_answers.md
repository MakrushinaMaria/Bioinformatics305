# Семинар 1: анализ 16S rRNA ампликонов в QIIME2

## Что мы анализировали

На семинаре мы работали с 16S rRNA sequencing data микробиоты мышей из эксперимента, где сравнивались группы с лабораторной и дикой микробиотой. Задача состояла в том, чтобы пройти основной amplicon workflow в QIIME2: проверить reads, получить ASV, определить их taxonomy, построить филогенетическое дерево и сравнить разнообразие микробных сообществ между группами.

В наборе было 29 paired-end образцов, то есть 58 FASTQ-файлов. Для образцов использовались обозначения групп `L`, `LR`, `W` и `WR`.

## Основные этапы

Мы выполнили полный workflow:

1. Проверили исходные FASTQ с помощью FASTQC и MultiQC.
2. Импортировали paired-end reads в QIIME2 и построили demux summary.
3. Провели denoising в DADA2, удалили sequencing errors и chimeras, объединили forward и reverse reads.
4. Получили ASV table и representative sequences.
5. Присвоили ASV taxonomy с помощью учебного V4 classifier и построили taxonomy barplot.
6. Выровняли representative sequences с MAFFT и построили rooted phylogenetic tree с FastTree.
7. Подготовили интерактивную визуализацию дерева в Empress.
8. Рассчитали phylogenetic core metrics, Shannon alpha diversity и weighted UniFrac beta diversity.
9. Сравнили группы по Shannon и провели pairwise PERMANOVA по weighted UniFrac distances.

## Результаты DADA2

Для DADA2 использовали `trim-left-f = 0`, `trim-left-r = 0`, `trunc-len-f = 220` и `trunc-len-r = 200`. Такие длины сохраняли качественную часть reads и оставляли перекрытие, необходимое для объединения paired-end последовательностей.

| Этап | Число reads | Доля от input |
|---|---:|---:|
| Input | 134 672 | 100,00% |
| Filtered | 109 500 | 81,31% |
| Denoised | 104 880 | 77,88% |
| Merged | 94 286 | 70,01% |
| Non-chimeric | 93 235 | 69,23% |

После фильтрации и удаления chimeras сохранилось около 69% исходных paired reads. Итоговая таблица содержала **516 ASV** в 29 образцах. Минимальная глубина была у W1 - 1392 reads, максимальная у LR2 - 4811 reads.

Для core metrics выбрали sampling depth **1300**. Это немного ниже минимального значения 1392, поэтому после rarefaction сохранились все 29 образцов.

ASV здесь означает точную последовательность исследованного ампликона, которую DADA2 считает реальным вариантом, а не sequencing error. В отличие от OTU, ASV не объединяются по условному порогу 97%. При этом один ASV не обязательно соответствует одному виду бактерий.

## Taxonomy и филогенетическое дерево

Для каждого ASV мы получили taxonomic assignment и построили интерактивный barplot относительного состава. Он позволяет сравнивать образцы и группы на разных taxonomic levels. Отдельно были получены aligned и masked sequences, unrooted tree и midpoint-rooted tree. В Empress taxonomy можно рассматривать вместе с положением ASV на дереве.

Эти результаты нужны не только для визуализации. Rooted tree используется при расчёте Faith's PD и UniFrac, то есть метрик, которые учитывают филогенетическое родство обнаруженных ASV.

## Alpha diversity: Shannon

Shannon index показывает разнообразие внутри одного образца и учитывает одновременно richness и равномерность abundances. Pairwise Kruskal-Wallis comparison показал различия почти между всеми группами:

| Сравнение | q-value |
|---|---:|
| L - LR | 0,00534 |
| L - W | 0,01308 |
| L - WR | 0,01166 |
| LR - W | 0,00534 |
| LR - WR | 0,17971 |
| W - WR | 0,00535 |

Единственное сравнение без статистически значимого различия после поправки - `LR` против `WR` (`q = 0,17971`). Для остальных пар `q < 0,05`. По самим значениям Shannon группа W в целом имела более низкое alpha diversity, а LR и WR были ближе друг к другу.

## Beta diversity: weighted UniFrac и PERMANOVA

Weighted UniFrac сравнивает образцы по филогенетическим ветвям и одновременно учитывает relative abundance. Это отличает его от unweighted UniFrac, где важнее само присутствие или отсутствие ветвей.

Pairwise PERMANOVA выполняли с 999 permutations. Для всех шести пар групп различия были статистически значимыми:

| Сравнение | pseudo-F | p-value | q-value |
|---|---:|---:|---:|
| L - LR | 5,319 | 0,001 | 0,0015 |
| L - W | 21,786 | 0,001 | 0,0015 |
| L - WR | 28,322 | 0,002 | 0,0020 |
| LR - W | 21,046 | 0,002 | 0,0020 |
| LR - WR | 24,756 | 0,001 | 0,0015 |
| W - WR | 8,825 | 0,001 | 0,0015 |

Таким образом, состав и relative abundance микробных сообществ связаны с группой. При этом PERMANOVA показывает различия между группами в distance matrix, но сама по себе не объясняет, какие именно taxa создают это разделение.

## Ответы на вопросы из семинара

**Откуда брали материал?** Выделяли бактериальную genomic DNA из кишечной микробиоты. РНК в этом анализе не выделяли: секвенировали участок гена 16S rRNA в бактериальной DNA.

**Какой участок секвенировали?** Гипервариабельный участок V4 гена 16S rRNA. Длина amplicon для пары 515F-806R составляет примерно 291 bp.

**Какая была длина reads?** Illumina MiSeq paired-end 2 x 250 bp.

**Какие primers использовали?** Универсальные bacterial primers 515F (`GTGCCAGCMGCCGCGGTAA`) и 806R (`GGACTACHVGGGTWTCTAAT`).

**Что означают вырожденные позиции?** Это IUPAC-коды: `N` - любой nucleotide A/C/G/T, `H` - A/C/T, `Y` - C/T. Такие позиции позволяют primers связываться с 16S sequences разных бактерий.

**Почему выбрали V4?** Этот участок достаточно вариабелен для сравнения bacterial taxa и при этом имеет удобную длину. Два reads по 250 bp сильно перекрываются на amplicon около 291 bp, поэтому paired-end reads можно надёжно объединить.

## Итог

Мы получили полный набор результатов от raw reads до ASV, taxonomy, phylogenetic tree и diversity statistics. После DADA2 осталось 93 235 non-chimeric reads и 516 ASV; все 29 образцов вошли в diversity analysis. Shannon показал сходство LR и WR при различиях между большинством остальных пар, а weighted UniFrac PERMANOVA обнаружил различия между всеми группами. Это означает, что экспериментальные группы отличаются по структуре микробных сообществ, причём различия видны как на уровне diversity внутри образцов, так и по phylogenetic composition между образцами.
